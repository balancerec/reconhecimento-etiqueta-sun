# Component mapping

- Dataset sidebar: search, SKU/SSCC/status filters and photo list.
- Central workspace: persistent SVG image viewer and zoom/pan/rotation.
- Workflow nav: five contextual stages.
- Geometry panel: smart click, aura, edit, isolate, perspective preview.
- Restoration Lab: single visible adjustment group, async processing status, derivatives/history, compare/export.
- Recognition panel: original OCR action; derivative OCR button disabled with explicit reason.
- Field Inspector: existing per-copy field evidence/review.
- Footer: save, approve, next, export.
